Exploratory Factor Analysis

In this section, we explore the dimensionality of the Michele instrument. First, the data is cleaned to only contain the Michele instrument responses. Then KMO and Bartlett’s tests are used to understand if the data is suitable for factor analysis. Second, the EFA is run for the cleaned data. Parallel analysis is used to understand how many factors are estimated to be in the data by simulating factor analyses. The number of factors for the actual EFA analysis is determined by this parallel simulation.

Prepping the data for EFA

Here, data is cleaned from the long format and to remove other varibles than those in the Michele instrument. The KMO is good overall (.85) and for the individual items (range = .78-.92). The Bartlett’s test (χ2(66) = 1447.01, p < .001) indicated items had sufficient correlations for factor analysis processes.

Running an EFA

Before performing an EFA, parallel analysis was used to determine the number of factors to retain. This determined that a three factor solution best fit the data, following the simulations (shown on Scree Plots).

Factor analysis was then conducted on the 12 item Michele instrument using a Maximum Likelihood method (ML) with an oblimin rotation. Considering the sample size (> 200) ML was used to further investigate the statistical significance of the obtained factor loadings (Hair et al., 2019). An oblique rotation method was employed because it is assumed that factors will be correlated (Tabachnick & Fidell, 2019).

Together, the three factors explain 64% of the variance. Factor 1 explains 23% of the variance (4 items), as does Factor 2 (4 items). Factor 3 explains 18% of the total variance (4 items). The communalities of the items, however, ranged from .389 (Q20_5) to .844 (Q20_10) (M = .64). # Expand multi-select columns 
expand_multiselect <- function(df, col) {
  all_opts <- df[[col]] |>
    na.omit() |>
    strsplit(" / ") |>
    unlist() |>
    trimws() |>
    unique() |>
    sort()

  for (opt in all_opts) {
    new_col <- paste0(col, "_", gsub("[^A-Za-z0-9]", "_", opt))
    df[[new_col]] <- as.integer(
      !is.na(df[[col]]) & grepl(opt, df[[col]], fixed = TRUE)
    )
  }
  df
}

# Analysis
use_mixed <- FALSE   # TRUE → lmer() + (1|EmpCount);  FALSE → lm()

fit_model <- function(outcome, rhs, mixed = use_mixed) {
  fml <- as.formula(paste(outcome, "~", rhs))
  if (mixed) {
    fml_mixed <- as.formula(paste(outcome, "~", rhs, "+ (1 | EmpCount)"))
    lmer(fml_mixed, data = score_df, REML = FALSE,
         control = lmerControl(optimizer = "bobyqa"))
  } else {
    lm(fml, data = score_df)
  }
}

extract_fixed <- function(model, outcome_name) {
  if (inherits(model, "lmerMod")) {
    coef_table <- coef(summary(model))
    ci         <- confint(model, parm = "beta_", method = "Wald")
  } else {
    coef_table <- coef(summary(model))
    ci         <- confint(model)
  }
  data.frame(
    outcome   = outcome_name,
    term      = rownames(coef_table),
    estimate  = coef_table[, "Estimate"],
    std.error = coef_table[, "Std. Error"],
    statistic = coef_table[, "t value"],
    p.value   = coef_table[, "Pr(>|t|)"],
    conf.low  = ci[rownames(coef_table), 1],
    conf.high = ci[rownames(coef_table), 2],
    row.names = NULL
  )
}

# plots
plot_coefs <- function(model, title = "") {
  coef_df <- extract_fixed(model, outcome_name = "")
  coef_df |>
    filter(term != "(Intercept)") |>
    ggplot(aes(x = estimate, y = reorder(term, estimate))) +
    geom_vline(xintercept = 0, linetype = "dashed", colour = "grey50") +
    geom_errorbarh(aes(xmin = conf.low, xmax = conf.high),
                   height = 0.2, colour = "steelblue") +
    geom_point(size = 2.5, colour = "steelblue") +
    labs(title = title, x = "Estimate (95% CI)", y = NULL) +
    theme_bw(base_size = 11)
}
